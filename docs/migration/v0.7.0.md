# Migrating to v0.7.0

## Every event carries `sequence-epoch`

`event-header` gains the mandatory leaf `sequence-epoch` (proto field
`sequence_epoch`). Producers mint a new opaque value whenever their
`sequence` counter can restart: a device reboot, a collector restart, or
failover to another producer. `sequence` now counts within one
(`source-device-id`, `sequence-epoch`) stream and increments by exactly 1.

- **Producers:** emit `sequence-epoch` on every event. Generate it at
  start-up (a boot id or a random token is enough).
- **Consumers:** treat a new epoch as a new stream, not as loss. Infer loss
  from gaps only when subscribed to the device's full stream. Deduplicate on
  `ce-id`, which is unchanged.
- **`ce-id` implementers:** add `sequence-epoch` to the leaves cleared
  before encoding, beside `sequence` and `observed-by`. Otherwise the id
  diverges per producer and per restart, and a retried publish no longer
  deduplicates.

## `mode-changed` field names

`prior` and `current` are now `previous-mode` and `mode` (proto
`previous_mode`, `mode`). Values are unchanged.
